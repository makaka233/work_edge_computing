# Slow 针对性学习修复：conditional-replay-v1

## 备份与范围

修复前代码已在当前分支提交：`0118622`。本次没有创建分支。
不改变 Fast、环境/需求、服务资源、抽样、KKT、对比算法或真实窗口奖励。
没有预定义候选部署、动作筛选、专家标签、模仿学习或算法替代 Actor。
保留所有训练日志、模型、结果和原有导出压缩包。

## 为什么修复

第103–122次更新与上一轮相同更新的负载完全一致，平均时延
187.34 / 188.08 ms，改善仅0.4%。Count 更新前 EV 20批中16批为负；
本批拟合后仍有8批为负。Placement 最近10批 KL 约4e-7、归一化熵0.964。
这些现象不证明单一根因，但不支持“Slow 已稳定学会良好部署”。

旧 deployment-aware-v2 每 epoch 汇总整批梯度只更新一次，
3个 epochs 对 Stage/Placement 只产生3步；旧完整训练每小批一步约9步。
这一优化节奏差异不能因为 epoch 名称相同就被忽略。

## 实现

### 1. 条件 Critic 的有限近期回放

每个头单独保留最近 `--slow-critic-replay-windows` 个窗口（默认96）。
Count 保留该窗口唯一预算状态；Stage/Placement 每窗口随机保留最多8个
决策前状态及其真实窗口回报。子抽样用独立随机流，不消耗 Actor/需求随机流。
每窗口总权重相同，按更新年龄以 `--slow-critic-replay-decay`（默认0.9）衰减。
多个窗口可以属于同一 Episode，不宣称96个窗口都是独立样本。

回放数据只有状态、原始回报、年龄；不回放动作、优势、旧策略标签。
Actor 仍仅使用当轮 on-policy 数据。有限历史回放只训练价值基线，
不是用历史动作训练 PPO。联合策略非平稳仍可能使历史价值过时，因此必须有限期/衰减。

Critic 使用归一化目标和 Huber 损失，缓解极端窗口的平方误差支配问题。
全批 Actor 更新不再顺带更新 Critic；Critic 单独训练默认8步。
每轮用当前图编码器重新编码有限历史状态一次，然后 detach；
8次拟合只运行 Critic MLP，不重复执行全量图网络。
不训练 Actor 图编码器，不改变其 Adam 动量。

### 2. 历史校准的基线倍率

Actor 优势仍来自真实回报，形式为 `R - c * V_before_action`。
`c` 在训练开始为0，以往批次估计 `clip(Cov(R,V)/Var(V),0,1)`，
按0.2指数平滑用于下一轮。它是降低基线噪声的启发式历史校准，
不是理论保证的最优策略梯度基线；未考虑 score 范数权重。

本轮 Actor 固定使用上一轮已保存的倍率和采样时价值预测。
不能用当前回报拟合当前动作的 baseline 后再更新当前 Actor。
差 Critic 不再必然以倍率1进入 Actor；Critic 仍继续训练，不分阶段冻结 Actor。

### 3. 完整 epoch 的小批更新与 KL 回退

一个 epoch 随机遍历当轮全部动作，每个小批执行一次 Actor 更新。
epoch 结束在整批数据上计算 KL；超过原阈值则恢复该 epoch 前的
全部参数和 Adam 状态，以半步长重新运行同一小批顺序，最多7次尝试。
已经接受的 epoch 保留；无法接受的 epoch 不提交。
没有只覆盖前几个负载就早停的批内遗漏，也没有放宽KL限制。
这恢复优化步数，不保证策略一定改得更多或时延一定更低。

## 启用、兼容与续训

新选项 `--slow-learning-repair auto|none|conditional-replay-v1`。

- 新建 deployment-aware-v2 训练：auto 启用新修复。
- 恢复旧 checkpoint：auto 保留 none，不静默改变旧训练机制。
- 旧 deployment-aware-v2 checkpoint 可显式开启新修复继续联合训练：
  Actor/Critic 网络形状不变，保留模型、Actor/Fast优化器及随机流，
  新增回放从空开始。只清理旧条件 Critic 的 Adam 动量（MSE切换Huber），
  不重置 Critic 权重；新修复检查点恢复时不会重复清理。
- 恢复新 checkpoint：保存并恢复基线倍率、回放状态和更新年龄。
- legacy、MSO 与对比评估 API 的默认路径不启用新学习机制。

建议显式切换学习机制时使用独立试验目录，保留原目录作为对照。
代码支持同目录 append；新增诊断写入不同文件，避免旧表头与新字段错位。
这里的“新目录”不是新 Git 分支，也不会复制或删除旧训练产物。

新增日志：`logs/slow_update_metrics_conditional_replay_v1.csv`。
保留原有更新/episode/rollout日志、样本覆盖、KL与步数，并补充各头
更新前 EV/MSE、更新后 MSE、基线倍率、本头回放窗口/样本数和独立价值步数。
更新前指标是顺序到来的新数据预测质量；更新后仅为本批拟合指标。
不能用本批 EV 声称泛化、收敛或优于其他方案。

## 验证边界

验证包括值特征与原 forward 等价、Critic 训练不改 Actor/Adam、

实际学习收益仍需同条件训练检验；短程功能检查不等于改进成功。
